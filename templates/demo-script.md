# Template, demo script

Audience: [A investors / B operators]. Length: [20 min live / 2 min recorded]. Covered metro: [name]. Address tested today: [yes / no, stop if no].
Method: `reference/demo-playbook.md`. Voice: `examples/demo-talk-track.md`.

## Before
- [ ] Address in a covered metro, forecast run today, confidence better than Low.
- [ ] Room Mix filled for every bedroom (avoids D-Q26).
- [ ] Deal Calculator inputs typed, including interest rate (avoids D-Q30).
- [ ] Host names and photos blurred if recorded for public use.

## Beats
1. **Open (30 seconds).** Their question, in their words. "You've got a house under contract and a room rent number in a spreadsheet."
2. **Market (2 minutes).** Dashboard, preset metro, Market Score list, map bands. Say what Thin means.
3. **Comparable property (4 minutes).** Analyzer: signal, room segments, best spread, windows. Do one reconciliation out loud.
4. **Their address (6 minutes).** Predictor: supply, baseline profile, run, read the formula, support, and confidence aloud.
5. **The deal (4 minutes).** Deal Calculator with typed inputs. "For information, not financial advice."
6. **Close (1 minute).** One call to action.

## Spoken rules
Short sentences. Read on-screen labels before interpreting them. Never skip a confidence or fallback label for pacing. Nothing UNVERIFIED shown as usable.

## After
Log the activity and every signal within 24 hours (`ops/activity-log.md`, `ops/signal-log.md`).

## Guardrails
`rules/writing-rules.md` writing for the ear. `rules/feature-status.md` demo rule. Lint and QA the script before recording.
