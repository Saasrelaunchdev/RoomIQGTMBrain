# Template library

One template per channel in the working mix (D-10), and only those. There are no templates for paid ads or cold outreach at volume, because this go-to-market does not produce them yet. That absence is a rule.

Every template ends with a guardrail line. A template is where a hurried operator stops reading.

| `demo-script.md` | Live demos and recorded walkthroughs | `reference/demo-playbook.md` | `examples/demo-talk-track.md` |
