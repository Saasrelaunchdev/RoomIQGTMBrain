# Demo playbook, founder-led demos

Load for: live demos, recorded walkthroughs, screenshots for any public surface. This is the second channel engine: demos are where status discipline breaks first. Distills: S1 screens 01 to 15, S2 QA issues, D-06.

## The demo path (covered metro, about 20 minutes)
1. **Dashboard.** Choose a Sun Belt metro preset. Show Top US markets by Market Score and the Explore map bands. Say what "Thin" means: too little evidence, not weak demand.
2. **Drawer.** Open a property. Read the revenue disclaimer aloud: "Based on observed rents and occupancy, not collected payments."
3. **Analyzer.** Property Signal, room segments, best spread, rolling windows. Do the arithmetic out loud: segment occupancy reconciles to the property.
4. **Visual comps.** Scroll past any non-bedroom photo without comment; never make one a talking point (D-Q18).
5. **Predictor.** Use an address in Dallas, Austin, Houston, Atlanta, Phoenix, or Tampa that you have tested that day. Show nearby supply, complete the room mix fully (avoids D-Q26), run the forecast, read the formula, the support level, and the confidence label aloud.
6. **Deal Calculator.** Type every input yourself, including the interest rate. Never show defaults (D-Q30, D-Q31). Say "for information, not financial advice".
7. **Close.** Offer to run the prospect's own address, if it is in a covered metro.

## Landmines, never on screen

| Defect | What happens | Avoid by |
|---|---|---|
| D-Q26 | Banner says full bedroom count; math uses 1.0 active rooms | Entering every room in Room Mix before running |
| D-Q28, D-Q29 | Uncovered address forecasts on comps 80+ miles away | Pre-tested covered addresses only |
| D-Q30, D-Q31 | Interest default may read 22%; vacancy may double count | Typing all inputs |
| D-Q18 | Closet photos in visual comps | Not dwelling on the grid |
| Q11 | Most DFW cells are Thin, the map looks empty | Zooming to a dense cluster |
| Q16 | A typo in Analyzer search matches title text | Typing city names exactly |

## Never shown as if a customer can use it today
Every UNVERIFIED capability: Forecasts tab, filters, views, report export, Trends and Rooms tabs, layouts, amenity ROI, house rules, rent guidance, cohorts, comp review, garage conversion compare. Clicking one live is allowed only if it was tested that day and the output is captured afterwards for a status AMEND.
