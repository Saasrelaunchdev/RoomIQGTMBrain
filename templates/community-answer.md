# Template, community answer

Audience: [A / B]. Where: [forum thread / group post / podcast Q&A]. The question, verbatim: "[paste]"

## Structure
1. **Answer the question first**, fully, without RoomIQ. Most of the value lives here.
2. **Show the reasoning** with one worked number, unit and window stated.
3. **Name the limit** of the answer: what you would need to know about their house.
4. **Mention RoomIQ only if it directly helps**, in one sentence, disclosed as your own product: "Disclosure: I'm building RoomIQ, which does X."
5. **No link unless the community allows it.**

## Rules
- Disclosure is mandatory whenever RoomIQ is mentioned.
- Never answer legal questions beyond "check local occupancy and rooming-house rules".
- Never suggest house rules tied to a protected class.
- Log the question as a LANGUAGE signal in `ops/signal-log.md`, verbatim.

## Guardrails
`rules/writing-rules.md` and `rules/do-not-say.md`. Lint and QA before posting.
