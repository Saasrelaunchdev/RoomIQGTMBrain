# Pages, finished long-form assets

Shipped copy lives here once it is approved and published: the live landing page, the methodology page, the design-partner invitation. The rule for this folder is update rather than rewrite, because a shipped page carries approvals a fresh draft does not.

Nothing has shipped under this brain yet (2026-11-13). Drafts live in `examples/` until the founder approves them.

When a page ships:
1. Save it here as `pages/<surface>.md` with its URL and approval date in the first lines.
2. Add the surface to `ops/asset-index.md` with the claim IDs it carries.
3. Log the release as an activity in `ops/activity-log.md`.
